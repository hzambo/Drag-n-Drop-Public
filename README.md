# Drag-n-Drop-VR
The goal of this project is to create an entry-level, fully configured Unity starter template. By providing a pre-built world environment and an extensive library of drag and drop assets, this template drastically lowers the barrier to entry for virtual reality content creation.

For directions on how to download and run the project, read this document: [Guide to Starting and Running the Project](https://docs.google.com/document/d/1N5YwVSKxrdcfuQWdwOqhYHreyPYD_T_NKrc2Mrq8qyE/edit?usp=drive_link)
